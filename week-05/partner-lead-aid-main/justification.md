# Week 10 — Path Selection: Test It

The Partner Referral Assistant already has a working end-to-end flow, so the next production risk is not whether we can demonstrate the happy path, but whether we can detect regressions when the system changes. Testing gives us a concrete safety net around the critical referral workflow before it is exposed to real users. The highest-risk boundary is the connection between the application and n8n: payload construction, workflow responses, malformed data, HTTP failures, and timeouts. Hardening this boundary makes the existing product more reliable without adding unnecessary architecture. It also demonstrates a production engineering skill that was less visible in the Week 9 demo: being able to prove that important behavior continues to work after changes.
